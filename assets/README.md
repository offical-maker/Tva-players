# TVA assets

Upload your own TVA screenshots, logos, and font files here.

Suggested filenames:
- `tva-hero.jpg` — optional hero artwork
- `tva-logo.png` — optional logo
- `dx-slight.woff2` — only if you have the licensed DX Slight font file

After uploading an asset, reference it from HTML/CSS with a path such as `assets/tva-hero.jpg`.
